# Code of conduct
Treat contributors and people represented in data with respect. Welcome newcomers, give specific
technical feedback, and tolerate good-faith mistakes. No harassment, discrimination, threats,
doxxing, personal attacks or publication of confidential information. Critique methods and evidence.

Report public concerns in a minimal moderation issue; ask for a private channel for sensitive
reports, following SECURITY guidance. The maintainer can warn, edit/remove harmful material,
restrict participation or ban repeated/serious misconduct, explaining action where privacy allows.
Appeals should give evidence and request an independent reviewer when available. This foundation
has one maintainer; no independent conduct committee or private channel is claimed.
