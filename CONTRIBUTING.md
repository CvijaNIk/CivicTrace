# Contributing
Start with [development](docs/DEVELOPMENT.md), [contributor guide](docs/CONTRIBUTOR_GUIDE.md)
and [backlog](docs/BACKLOG.md). Ask on an issue before substantial changes to avoid duplicated work.
Use synthetic fixtures, cite methods, and disclose source rights and material conflicts of interest.
Contributions are under the existing Apache-2.0 license; do not import proprietary project code.

Create a focused branch/PR, explain observable behavior, link the issue, distinguish implemented
features from proposals and report exact checks run. New rules/connectors need positive, negative,
missing-input, boundary and provenance tests; statistics need assumptions and sensitivity checks.
Run tests, lint, formatting and relative-doc-link checks. Update CURRENT_STATE for meaningful
changes. Review waits for maintainer capacity; no guaranteed merge SLA.

Never attach client files, credentials or sensitive allegations. Report security problems using
[SECURITY](SECURITY.md), and respect [data policy](DATA_POLICY.md) and [conduct](CODE_OF_CONDUCT.md).
